# Variables

* Use lowercase only.
* Use letters, numbers, and underscores (`_`) only.
* Do not use spaces, hyphens, camelCase, or other special characters.
* Keep names descriptive but concise.
* End content variables with a _number, this for easy duplication and consistency between blocks. img_1, txt_1
* Links: the variable holding a URL is `{type}_link_N` (`img_link_1`, `btn_link_1`, `icon_link_1`). The old generic
  `url_N` is retired.

Here is everything in the same easy-to-copy table format.
